### Everything you love, on your Mac

All the powerful features of Notepad++, built to feel right at home on macOS.

| | Feature | Description |
|---|---|---|
| `</>` | **Syntax Highlighting** | Support for 80+ programming languages with customizable color themes and user-defined languages. |
| :gear: | **Plugin Ecosystem** | Extend functionality with a rich plugin ecosystem. Customize your editor to match your workflow. |
| :zap: | **Apple Silicon Native** | Built for M-series chips. Launches instantly, runs efficiently, and respects your battery life. |
| :mag: | **Search & Replace** | Powerful search with regular expressions, find in files, bookmark lines, and incremental search. |
| :window: | **Split View Editing** | View and edit two documents side by side, or two parts of the same document simultaneously. |
| :play_or_pause_button: | **Macro Recording** | Record, save, and replay macros to automate repetitive editing tasks with ease. |
| :globe_with_meridians: | **Native Language Support** | Switch Notepad++ to the language you speak. It supports 137 languages out of the box. |
